# 数据库类系统设计评审

一个用于评审数据库类（database-like）系统及相关系统模块的交互式技能。它通过检查真实代码和文档，围绕模块边界、状态所有权、数据流、成本与故障语义，逐步推进架构设计决策。

它适合以下类型的工作：

- 梳理现有系统的模块职责、边界和依赖关系；
- 设计或评审存储引擎、WAL/日志服务、缓存、恢复、元数据等组件；
- 比较不同的状态所有权、数据流、持久化和故障处理方案；
- 在架构重构前，基于代码和文档识别真实约束与潜在风险。

评审以交互式设计讨论为主，一次聚焦一个重要决策，并在证据基础上给出明确建议。它不以一次性生成完整架构报告、普通故障修复或逐行代码审查为主要目标。
